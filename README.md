# Risk-Adjusted Performance Analysis — Indian Stocks vs Nifty 50

Comparing TCS, HDFC Bank, Reliance, and Infosys against the Nifty 50 
benchmark (2021-2025) using Sharpe Ratio, Excess Return (Alpha), 
Maximum Drawdown, and correlation analysis.

## Tools Used
- Python
- yfinance
- pandas
- matplotlib
- seaborn

## Key Findings
- Nifty 50 had the best Sharpe Ratio (0.51) of all five — beating every individual stock
- Only Infosys generated positive Alpha (+1.16%) against the benchmark
- Infosys had the best risk-adjusted return but also the worst drawdown (-35.6%)
- Nifty 50 had the smallest maximum drawdown (-17.2%) — confirming the 
  diversification benefit of index investing over individual stock picking
